Terraria Access makes Terraria playable for blind and low-vision players. It provides full screen reader narration and spatial audio cues so you can explore, fight, build, and craft without needing to see the screen.

[b]Screen Reader Narration[/b]
Every menu, inventory screen, crafting interface, NPC dialogue, and chat message is narrated through your screen reader. Supports JAWS, NVDA, SuperNova, System Access, ZoomText, and Windows SAPI via the Tolk library.

[b]Spatial Audio & Navigation[/b]
- Footstep sounds that change with terrain
- Edge detection warns you about drop-offs with directional static or beeps
- Fall detection reuses edge-style beeps to warn when dangerous falls approach the ground
- Wall collision taps tell you which side is blocked
- Enemy proximity audio cues with interaural timing for precise left/right position

[b]Guidance System[/b]
Track and navigate to NPCs, other players, dropped items, critters, interactable objects, and custom waypoints. Audio pings guide you toward your target with interaural timing, distance volume, and pitch.
- Saved custom trackers for typed item, NPC, object, and tile targets
- Sweep or Nearest Only mode for "All" guidance categories
- Expanded exploration targets including statues, fossils, Jungle Spores, Abigail's Flower, Nature's Gift, Enchanted Sword shrines, crystal shards, amber gems, herb bloom stages, and fallen stars

[b]Inventory & UI[/b]
- Full keyboard navigation of inventory, equipment, crafting, shops, and chests
- Gamepad emulation lets keyboard users access controller-only UI features
- First-letter navigation to quickly find items
- Spatial inventory audio positions slot sounds by visible screen column and row
- Mod browser, mod config, achievements, and bestiary screens are all narrated
- Journey mode powers, research, sliders, and toggles are narrated
- Character/world naming, signs, chat, and custom tracker prompts support accessible text input

[b]Combat & World[/b]
- Damage number announcements
- Health heartbeat that speeds up as HP drops
- Lock-on target narration
- Boss attack warnings with brief dodge guidance for many boss patterns and dangerous projectiles
- Armor set bonus, minion slot, info accessory, death, and respawn announcements
- World event announcements: blood moons, invasions, eclipses, weather, biome changes, event progress, lunar pillars, and more

[b]Building[/b]
- Build mode for keyboard-driven tile placement without a mouse
- Chunk miner automatically mines entire ore veins in one hit
- Smart cursor tile narration, build mode wiring support, and wire color menu access

[b]Multiplayer[/b]
- Spatialized footstep sounds for other players
- Player join/leave/death announcements
- Optional multiplayer guidance and chunk miner sync

All features are configurable in the mod settings. Volumes, toggle switches, and detection modes can be adjusted to your preference.

Requires Tolk.dll in your tModLoader directory. See the GitHub page for installation instructions.
