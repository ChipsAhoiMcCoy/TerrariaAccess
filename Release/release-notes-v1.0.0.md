# Terraria Access 1.0.0 Release Notes

Terraria Access 1.0.0 is the first stable release, with expanded coverage across Journey mode, guidance, combat, world events, text input, multiplayer behavior, and keyboard/gamepad emulation.

## Highlights

- Added Journey mode accessibility for the Journey toggle, research, duplication, powers, sliders, and blocked-state announcements.
- Added boss attack warnings for many major bosses, event bosses, dangerous projectiles, and pressure states.
- Added event progress narration for invasions, moon events, lunar pillars, pillar shields, and the Moon Lord countdown.
- Added an info accessory checker for watch, compass, depth meter, radar, tally counter, lifeform analyzer, stopwatch, DPS meter, metal detector, fishing power, weather, and moon phase.
- Reworked custom guidance into saved custom trackers with typed target input for tiles, objects, dropped items, NPCs, enemies, critters, projectiles, and players.
- Added Guidance All Mode, allowing All-category pings to use either Sweep or Nearest Only behavior.
- Expanded exploration guidance targets, including statues, fossils, Jungle Spores, Abigail's Flower, Nature's Gift, Enchanted Sword shrines, crystal shards, amber gems, herb bloom stages, and fallen stars.
- Added Build Mode wiring support.
- Added armor set bonus announcements and minion slot usage announcements.
- Improved death and respawn narration.
- Improved accessible text input for character names, world names, signs, chat recovery, waypoint naming, and custom tracker prompts.
- Improved keyboard gamepad emulation across menus, inventory, shops, dialogue, smart cursor, D-pad hotbar behavior, quick use, and smart select.
- Added optional multiplayer sync behavior for guidance and chunk miner features while preserving client-only accessibility use.

## Notes

The bundled documentation has been updated for these systems. Input profile bindings may differ from the key names shown in the manual if a custom or newer input profile is installed.
